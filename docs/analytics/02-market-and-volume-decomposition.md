## 2. 10-Way Volume Decomposition Breakdown (§14)

Traditional token screeners report gross volume blindly ($3.2M). Project Sentinel breaks volume into 10 distinct quantitative components:

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 10-WAY VOLUME DECOMPOSITION ARCHITECTURE                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Buy Volume: Gross USD value of all purchase swap transactions            │
│ 2. Sell Volume: Gross USD value of all token disposal swap transactions     │
│ 3. Unique Buyer Volume: Purchases executed by first-time daily unique addresses│
│ 4. Unique Seller Volume: Sales executed by first-time daily unique addresses│
│ 5. Repeat-Wallet Volume: Trading volume generated by recurring addresses     │
│ 6. New-Wallet Volume: Transactions by wallets created within past 24 hours  │
│ 7. Creator-Linked Volume: Trades by addresses linked to the token deployer   │
│ 8. Insider-Linked Volume: Trades by addresses funded by early insiders       │
│ 9. Suspected Wash Volume: Circular or synchronized manipulative volume      │
│ 10. Verified Organic Volume: True retail / decentralized market participation│
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. Organic Volume Scoring Formula (§15)

The Organic Volume Score ($0 - 100$) represents the statistical probability that observed trading volume originates from genuine independent market participants:

$$\text{Organic Volume Pct} = \frac{\text{Organic Volume USD}}{\text{Total Observed Volume USD}} \times 100$$

$$\text{Diversity Factor} = \min\left(1.0, \frac{\text{Unique Participants}}{50}\right)$$

$$\text{Organic Score} = \min\left(100, \text{round}(\text{Organic Volume Pct} \times 0.8 + \text{Diversity Factor} \times 20)\right)$$

## 4. Wash Trading Pattern Detection Heuristics (§16)

The engine monitors the trade stream for four primary wash trading patterns:
1. **Circular Trading Rings ($A \rightarrow B \rightarrow A$)**: Reciprocal buying and selling between pairs or small clusters of wallets within minutes of each other.
2. **Synchronized Same-Size Orders**: Multiple transactions executing for identical dollar or token amounts (e.g. exactly $\$5,000.00$) in fixed intervals.
3. **High-Frequency Flip-Flopping**: Wallets holding tokens for $< 60$ seconds with zero net inventory accumulation.
4. **Funded Wash Clusters**: Multiple participant wallets whose initial SOL gas fees originated from the exact same master funding address within a shared 30-minute window.
