# Exitability

"Can I actually get out of this position, and at what cost." Simulates
exiting a reference position against real liquidity/curve/route data, runs
stress tests, and generates the alert events that feed
[webhook delivery](./webhooks.md) for this domain.

**Scope:** `READ_TOKEN_INTELLIGENCE`. **Auth:** `optionalAuth`.

| Endpoint | Returns |
|---|---|
| `GET /api/v1/exitability/:chain/:token?amount=5000` | Score, confidence, expected output, price impact, slippage, liquidity, exit depth, stress score, curve, warnings, `alertEvents` |

`amount` is the reference position size in USD (defaults to the context's
own reference size if omitted).

Every response has `isSimulation: true` — this is a model of what exiting
would cost, never a live quote.

## Alert events

Each response includes `alertEvents`: real events generated by
`buildExitabilityAlertEvents` (`EXITABILITY_DROP`, `LIQUIDITY_DROP`,
`LARGE_LIQUIDITY_WITHDRAWAL`, `EXIT_DEPTH_COLLAPSE`, `SLIPPAGE_SPIKE`,
`POOL_CONCENTRATION_CHANGE`, `STRESS_EXITABILITY_DROP`) when the underlying
report crosses a threshold. Every call to this endpoint also broadcasts
those same events to any webhook subscribed to the matching event type — see
[`alerts.md`](./alerts.md) for the mapping and
[`webhooks.md`](./webhooks.md) for delivery.

```bash
curl "https://your-host/api/v1/exitability/solana/QUANT?amount=10000" \
  -H "Authorization: Bearer sk_live_..."
```
